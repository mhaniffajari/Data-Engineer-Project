1. How to extract product:
python .\get_product_tokopedia.py 'merchant name'
example
python .\get_product_tokopedia.py 'moell-official'

2. How to extract review:
python .\get_review_tokopedia.py 'merchant name' count of page
example
python .\get_review_tokopedia.py 'moell-official' 5


3. How to convert HTML to CSV

python .\tokopedia_html_to_csv.py
